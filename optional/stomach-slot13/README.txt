Body Pouches - Stomach Slot 13 Preset (0.2.0)

Optional settings mod for Body Pouches and VRIK 0.8.7. Enables stomach
slot 13, allows both hands, and supplies the belly position accepted in
the author's headset test. No plugin or DLL is included.

INSTALL
Install this archive as a separate mod with MO2 or Vortex. Its file
SKSE/Plugins/vrikslots.ini must win conflicts against VRIK and any other
VRIK slots configuration. Launch the game normally through SKSEVR.

CUSTOM VRIK SLOTS
VRIK reads a whole vrikslots.ini, not an automatic merge. This preset
includes the baseline settings for the other holsters. If you customized
other slots, keep your file and copy only enableHolsters plus the keys
ending in 13 (visibleSlot13, hoverHaptics13, handSlot13, allow*Slot13,
pos*13 and rot*13) from this preset into it instead.

FIT AND USE
Calibrate your body normally in VRIK. Belly position depends on body
size; adjust slot 13 in VRIK MCM if needed. The preset does not assign a
potion: hold a drinkable potion and release it inside the slot once.
Body Pouches uses this slot as its exclusive potion pouch by default.

UNINSTALL
Disable this settings mod to restore the lower-priority VRIK file.
