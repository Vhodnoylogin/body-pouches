# Body Pouches — 0.2.0

Зелья под рукой в Skyrim VR. Превратите слот на теле VRIK в сумку для зелий:
возьмите бутылку любой рукой, выпейте через HIGGS или верните в слот.
Для обращения с сумкой не нужны меню инвентаря, колесо выбора или отдельная горячая клавиша.

English: [README.md](README.md).

## Возможности

- По умолчанию одна сумка exclusive в слоте «живот» (13).
- Видимая бутылка показывает следующее подходящее зелье.
- Назначение, взятие и возврат движениями рук.
- Выбор из обычного инвентаря по эффектам, включая составные зелья.
- Отдельные назначения в каждом сейве после загрузки и полного перезапуска.
- Яды отвергаются; отдельный запас предметов не создаётся.

## Требования и начало игры

Для Skyrim VR. Установите зависимости ниже, включите `BodyPouches.esp` и запускайте через SKSEVR. DevBench для игры не нужен.

- [SKSEVR](https://skse.silverlock.org/)
- [VR Address Library for SKSEVR](https://www.nexusmods.com/skyrimspecialedition/mods/58101)
- [VRIK Player Avatar](https://www.nexusmods.com/skyrimspecialedition/mods/23416), 0.8.7
- [HIGGS](https://www.nexusmods.com/skyrimspecialedition/mods/43930)
- [SkyUI-VR](https://github.com/Odie/skyui-vr/releases) для MCM VRIK; установите указанные на его странице зависимости.
- Microsoft Visual C++ Redistributable x64 (v14), необходимый собранной DLL.


Включите в VRIK слот «живот»13, возьмите питьевое зелье и отпустите его
внутри слота: это назначит сумку. Для взятия сожмите хват пустой рукой в зоне
и выведите руку, удерживая хват. Поднесите бутылку ко рту для питья через HIGGS
или отпустите в слоте, чтобы вернуть. Сохраняйтесь обычным способом и держите
ESS/SKSE вместе. Старому сейву без записи нужно один раз назначить сумку
и снова сохраниться.

Подробности настройки, составных зелий, положения и обновления —
в [руководстве](docs/quick-start.ru.md).

## Известные ограничения

Принятая база релиза — стандартная сумка exclusive для зелий. Две руки могут
попадать в штатную зону активации в разных видимых точках: горлышко бутылки
не является её центром. Это оставшееся замечание к удобству исследуется.
Shared и несколько слотов — расширенные настройки с более узкой проверкой.
Владелец вручную принял положение, взятие/возврат обеими руками, питьё и разные
назначения лечения/магии после загрузок и полного перезапуска.

## Сборка исходников

```text
cmake -S . -B build-core -DBODYPOUCHES_BUILD_PLUGIN=OFF
cmake --build build-core --config Release
cmake -S . -B build
cmake --build build --config Release --target BodyPouches
```
