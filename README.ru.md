Отдельный репозиторий, выделенный из [Skyrim-Mods](https://github.com/Vhodnoylogin/Skyrim-Mods), ветка `body-pouches`, 02.10.2026.

Основная ветка — `main`. Здесь находятся только этот модуль и его вспомогательные файлы.

Действующий репозиторий темы `potion-pouches` — [Vhodnoylogin/body-pouches](https://github.com/Vhodnoylogin/body-pouches).
Новые изменения выполняются здесь, в `main`; прежние рабочие копии `Skyrim-Mods` служат историей.
03.10.2026 перенос всех 25 относящихся к модулю и его правилам игнорирования коммитов сверён
по содержимому, авторству, сообщениям и связям истории. После проверки прежняя ветка
`body-pouches` в `Vhodnoylogin/Skyrim-Mods` удалена локально и на GitHub; её рабочая копия сохранена
на прежнем коммите без привязки к ветке.
