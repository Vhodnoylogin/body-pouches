# Body Pouches 0.2.0

Зелья под рукой в Skyrim VR. Назначьте слот на теле бутылкой, возьмите следующее
подходящее зелье рукой, выпейте через HIGGS или верните в слот. По умолчанию
используется слот VRIK «живот» (13), доступный обеим рукам.

## Требования и установка

- Skyrim VR.
- [SKSEVR](https://skse.silverlock.org/)
- [VR Address Library for SKSEVR](https://www.nexusmods.com/skyrimspecialedition/mods/58101)
- [VRIK Player Avatar](https://www.nexusmods.com/skyrimspecialedition/mods/23416), 0.8.7
- [HIGGS](https://www.nexusmods.com/skyrimspecialedition/mods/43930)
- [SkyUI-VR](https://github.com/Odie/skyui-vr/releases) для MCM VRIK; установите указанные на его странице зависимости.
- Microsoft Visual C++ Redistributable x64 (v14), необходимый собранной DLL.

Установите архив через менеджер модов и включите мод и `BodyPouches.esp`.
Запускайте игру через SKSEVR. Архив не содержит DLL других модов и не заменяет
VRIK, HIGGS или вашу личную настройку VRIK. PLANCK для механики зелий не требуется.
DevBench для игры не нужен. Версия предназначена для Skyrim VR; поддержка
обычной SE/AE не заявлена.

## Первая сумка

1. В MCM VRIK включите слот «живот» (13). Для обнаружения слота VRIK требует
   хотя бы один разрешённый тип оружия. Body Pouches отдаёт этот слот зельям
   в режиме exclusive; одновременно использовать его как оружейную кобуру не нужно.
2. Возьмите питьевое зелье через HIGGS. Поднесите удерживающую руку в слот и
   отпустите хват внутри него. Простое касание бутылкой тела её не укладывает.
   Вибрация при входе в зону помогает найти слот.
3. Пустой рукой сожмите хват внутри слота и выведите руку, продолжая удержание.
   В руке появится подходящее зелье. Поднесите его ко рту для питья через HIGGS
   или отпустите в слоте, чтобы вернуть.
4. Сохраните игру обычным способом. При переносе сейва держите `.ess` и `.skse`
   вместе: каждое сохранение запоминает собственное назначение сумки.

Сумка выбирает зелья из обычного инвентаря и не создаёт отдельное хранилище.
Видимая бутылка показывает следующее подходящее зелье, а не дополнительный предмет.
Когда запас кончается, изображение исчезает, но назначение остаётся.

Назначение запоминает все эффекты исходного зелья. Бутылка с лечением и магией
задаёт выбор зелий с лечением **или** магией, а не только с сильнейшим эффектом.
Сначала выдаются зелья с меньшим числом эффектов, затем с меньшей максимальной
силой эффекта, затем по идентичности плагина/формы. Яды отвергаются. Зелье без
эффектов задаёт выбор своей точной формы.

## Положение и настройки

Подберите положение штатной настройкой кобуры VRIK. Бутылка наследует поворот
слота. После настройки заблокируйте кобуры в VRIK, чтобы длинный хват не сдвигал
их случайно. Чужая калибровка не является универсальной посадкой для вашего тела.

При первом запуске создаётся `SKSE/Plugins/bodypouches/bodypouches.json` в
виртуальном Data, часто в overwrite менеджера модов. Настройки по умолчанию:

```json
{
  "language": "english",
  "logLevel": "info",
  "mayEnableSlots": false,
  "pouches": [{ "slot": 13, "mode": "exclusive" }]
}
```

Меняйте настройки при закрытой игре. `mayEnableSlots` явно разрешает включить
настроенные слоты в памяти; по умолчанию это отключено. Пустой массив `pouches`
выключает сумки. Shared и несколько слотов — расширенные настройки; принятая
база этого релиза — одна стандартная сумка exclusive.

## Обновление и известные ограничения

Сейвы до 0.1.21 не содержат записи назначения: назначьте сумку один раз и снова
сохранитесь. Оставшееся в старом сейве изображение бутылки не заменяет запись.
Отсутствующие формы или неподдерживаемые записи оставляют соответствующее
назначение пустым; причина записывается в журнал.

Правая и левая рука могут попадать в зону в разных видимых точках. Проверяется
геометрия руки и слота VRIK, а не горлышко или поверхность бутылки. Это оставшееся
замечание к удобству исследуется. Перед новой попыткой полностью выйдите из зоны
и отпустите хват: быстрый повтор может попасть под штатную задержку VRIK.
Мод не увеличивает радиус штатной зоны.

Владелец вручную принял положение, взятие и возврат обеими руками, питьё и разные
назначения лечения/магии после загрузок и полного перезапуска. Это не означает
исчерпывающую проверку каждой конфигурации, гонки или модели шлема.
