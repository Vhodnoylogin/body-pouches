The registry remains the source of client-lease existence and save generation; the region service observes these through narrow private getters rather than owning another save scope.

For stage two, audit existing CommonLib geometry and transform facilities before extracting any missing pure distance helper. Region definitions, observed-pair history, dwell thresholds, user customization, grants and gameplay do not move into CommonLib. PPB anatomy/fitting and HIGGS/PLANCK physical ownership remain unchanged. No CommonLib method, source, address binding or dependency was modified.

The subsequent optional HIGGS native mouth/stash adapter also adds no engine address or required library extension. It copies existing HMD/hand/palm/configuration observations and uses Body Slots's shared distance kernel. The original HIGGS float fallback and double-precision shared kernel can differ near rounding boundaries; an eventual common math helper must make precision, surface inclusion, units and transform scale explicit rather than silently claiming bit-identical parity. Callback ownership, per-hand source generations, runtime discovery, replay refusal and native action admission remain service-level contracts. CommonLib work is still analysis/preparation only.
